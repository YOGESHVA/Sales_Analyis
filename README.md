\# Sales Analysis Project



\## Project Overview

This project analyzes sales data to identify business insights.



\## Objectives

\- Analyze total sales.

\- Identify top-performing products.

\- Understand monthly sales trends.



\## Technologies Used

\- Python

\- SQL

\- Excel

\- Power BI



\## Dataset

Sales transaction data containing product,

quantity, price, and order date.



\## Project Workflow

1\. Data collection

2\. Data cleaning

3\. Data analysis

4\. Data visualization



\## Key Insights

\- Identify the highest-selling products.

\- Analyze monthly revenue trends.



\## Conclusion

This project helps understand sales performance

and supports better business decisions.
